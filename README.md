# Telecom Churn Dashboard

## Overview

Analyzed telecom customer data to summarize key metrics and predict churn.  
Built an interactive Power BI dashboard and a Random Forest model for churn prediction.

## Tools

- **SQL (SSMS):** Data extraction and cleaning
- **Power BI:** Dashboard and visualization
- **Python:** Random Forest model for churn prediction

## Deliverables

- Power BI dashboard showing customer and churn insights
- Python model predicting customer churn
